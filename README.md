# LiveDesk

움직이는 바탕화면 + 바탕화면 에디터.

```
livedesk/
  app/index.html     렌더러 + 에디터 (단일 파일, 의존성 없음, Canvas 2D)
  host/              Windows 호스트 (C# / .NET 8 / WebView2) — 바탕화면 아이콘 뒤에 렌더러를 붙임
```

## 에디터만 바로 써 보기

`app/index.html`을 브라우저(Chrome/Edge)로 열면 됩니다. `app/index.html?mode=wallpaper`는 배경화면 전용 화면입니다.

- 이미지: 업로드 버튼 / 캔버스에 드래그 / Ctrl+V 붙여넣기
- 배치: 드래그로 이동, 모서리 핸들로 크기(Shift = 비율 해제), 위쪽 핸들로 회전(Shift = 15° 단위)
- 움직이는 GIF: 일반 이미지처럼 올리면 그대로 재생됩니다 (최대 400프레임, 메모리가 크면 자동 축소)
- 움직임: 둥실둥실, 흔들흔들, 회전, 맥동, 깜빡임, 원 궤도, 흘러가기, 떨림, 마우스 따라 움직임 — 여러 개 중첩 가능
- 직접 그린 경로: 움직임에서 "직접 그린 경로"를 추가하고 캔버스를 클릭해 점을 찍으면 그 길을 따라 움직입니다. 점 드래그로 수정, Backspace로 마지막 점 삭제, Enter로 완료. 왕복/한 바퀴/점프, 곡선, 가감속, 진행 방향 회전 선택
- 프리셋: 분류별로 접었다 펼 수 있습니다 — 시계·날짜 / 텍스트 / 도형 / 날씨·계절 / 빛·우주 / 물·공기 / 축하·장식 / 직접 만들기
- 직접 만드는 파티클: 파티클 종류를 "직접 만들기"로 두면 낱개 모양을 기본 도형 9종이나 내 이미지(GIF 포함)로 고르고, 방향·퍼짐·회전·흔들림·크기 차이·깜빡임·알록달록을 조절할 수 있습니다
- 단축키: Ctrl+Z / Ctrl+Y, Ctrl+D 복제, Delete 삭제, 방향키 이동(Shift = 10px), Esc 선택 해제
- 내보내기/불러오기: 이미지까지 포함한 `.livedesk.json` 한 파일

## 실제 바탕화면에 적용 (Windows 10/11)

[.NET 8 SDK](https://dotnet.microsoft.com/download)가 필요합니다. WebView2 런타임은 Windows 11과 최신 Windows 10에 기본 포함되어 있습니다.

```bash
cd host
dotnet run -c Release
```

배포용 exe:

```bash
dotnet publish -c Release -r win-x64 --self-contained false -o ../dist
```

실행하면 LiveDesk 창과 트레이 아이콘이 생깁니다. 창을 닫아도 트레이에서 계속 실행되며, 아이콘을 더블클릭하거나 exe를 다시 실행하면 창이 다시 열립니다.

- **내 바탕화면(보관함)**: 저장해 둔 바탕화면이 카드로 나열됩니다. 미리보기나 **사용하기**를 누르면 바로 그 바탕화면으로 바뀝니다. 새로 만들기 / 편집 / 이름 변경 / 복제 / 삭제 / 파일에서 불러오기.
- **편집기**: 카드의 **편집**을 누르면 같은 창 안에서 열립니다. 변경 내용은 자동 저장되고, **바탕화면에 적용**을 누르면 즉시 반영됩니다. **← 목록**으로 돌아갑니다.
- **바탕화면 켜짐/꺼짐**: 창 오른쪽 위 스위치(또는 트레이 메뉴). 끄면 원래 Windows 배경화면으로 돌아가고, 상태는 다음 실행에도 유지됩니다.
- 트레이 메뉴: LiveDesk 열기 / 바탕화면 켜기 / Windows 시작 시 자동 실행(창 없이 트레이로 시작) / 종료.

## 부하를 줄이는 방식

- 움직이는 요소가 있을 때만 FPS 제한(기본 30) 루프를 돌리고, 시계만 있으면 1초에 한 번, 완전히 정적이면 변경 시에만 그립니다.
- 전체화면·최대화 창이 덮은 모니터의 배경화면은 그리기를 멈춥니다(호스트가 감지).
- 파티클은 한 번의 path/스프라이트로 묶어 그리며, 품질(해상도 배율)과 FPS를 장면마다 조절할 수 있습니다.
- 4096px을 넘는 이미지는 업로드 시 축소합니다.
